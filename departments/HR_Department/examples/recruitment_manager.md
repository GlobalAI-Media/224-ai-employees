## 2. SKILL TAXONOMY FOR AI WORKFORCE

### 2.1 Core Skill Categories
We define four macro-skill clusters for all AI agents:

| Cluster | Example Skills | Proficiency Levels |
|---------|----------------|-------------------|
| **Technical Core** | Model architecture, Training optimization, Inference tuning, Data preprocessing | L0 (None) → L4 (Expert) |
| **Cognitive & Reasoning** | Logic reasoning, Problem decomposition, Multi-step planning, Uncertainty handling | L0 → L4 |
| **Collaborative & Communication** | Inter-agent handoff, Human-AI interaction, Report generation, Debugging explanation | L0 → L4 |
| **Ethics & Compliance** | Bias detection, Explainability, Privacy preservation, Regulatory alignment | L0 → L4 |

### 2.2 Role-Skill Matrix (Example for NLP Engineer)

| Skill | Required Level (L0–L4) | Current Average Level | Gap |
|-------|------------------------|-----------------------|-----|
| Transformer Architecture | L4 | L3 | L1 |
| Fine-tuning (LoRA, PEFT) | L3 | L2 | L1 |
| Multilingual Tokenization | L3 | L1 | L2 |
| RLHF Implementation | L3 | L1 | L2 |

### 2.3 Implementation Steps
1. **Audit Current Agents**: Run automated skill assessments every 90 days using internal test suites.
2. **Define Role Profiles**: For each target role, publish a “Skill Blueprint” with minimum proficiency thresholds.
3. **Talent Sourcing Strategy**:
   - **Internal Upskilling**: 40% of new capabilities via retraining current agents (focus on L1→L2 gaps).
   - **External Recruitment**: 60% via new AI agent acquisitions (focus on L3–L4 gaps).
