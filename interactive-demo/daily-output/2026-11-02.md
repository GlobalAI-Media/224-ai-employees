# Shipping Route Outline: Shanghai → Dubai (Consumer Electronics)

## Recommended Primary Route: Direct Ocean Freight

**Route:** Shanghai (Yangshan Port) → Strait of Malacca → Indian Ocean → Arabian Sea → Jebel Ali Port, Dubai

- **Transit time:** ~18–22 days port-to-port
- **Service options:** Direct calls via major carriers (e.g., CMA CGM, Maersk, COSCO) or transshipment via Singapore/Colombo if direct space is constrained
- **Vessel type:** Fully cellular container ships; 40ft HC containers recommended for electronics (volume-efficient, better cubic utilization)

## Alternative Options

| Mode | Route | Transit | Notes |
|------|-------|---------|-------|
| Ocean (transshipment) | Shanghai → Singapore → Jebel Ali | 22–28 days | Use when direct vessel space is tight |
| Air freight | PVG → DXB (direct or via HKG) | 1–2 days | For high-value, time-sensitive SKUs |
| Sea-Air | Shanghai → Singapore (sea) → DXB (air) | 12–15 days | Cost/time balance for urgent replenishment |
| Rail (via China-Europe corridor + feeder) | Not cost-effective for UAE | — | Generally not recommended |
